ℹ️ OSINT Lab

Plataforma de práctica personal

¿Qué es OSINT Lab?
Una plataforma de práctica OSINT, SOCMINT e IMINT con casos simulados de nivel creciente. Diseñada para practicar sin parar y prepararse para análisis de inteligencia real.

Niveles de dificultad:
🟢 Nivel 1 — Técnica única, herramientas básicas
🟡 Nivel 2 — Múltiples fuentes, correlación de datos
🟠 Nivel 3 — Multidisciplinar, análisis avanzado
🔴 Nivel 4 — Caso completo de inteligencia con informe estructurado

¿Cómo se corrige?
Cada caso tiene un prompt de corrección. Realiza el ejercicio, copia el prompt al chat de Claude, pega tu análisis y recibe evaluación estructurada con rúbrica.

Datos locales: Tu diario de práctica se guarda solo en este navegador (localStorage). No se envía ningún dato a servidores externos.
